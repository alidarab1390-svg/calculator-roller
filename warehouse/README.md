# سامانه انبار آسارول — Warehouse (رولیک‌سازی)

برنامه نصب‌شدنی (PWA) برای مدیریت انبار رولیک‌سازی: بدون اینترنت کار می‌کند، اطلاعات روی همان دستگاه ذخیره می‌شود و در صورت فعال‌سازی با ابر (Google Sheets) همگام و گزارش ارسال می‌کند.

آدرس پس از انتشار روی GitHub Pages: `https://<user>.github.io/calculator-roller/warehouse/`

## امکانات
| بخش | توضیح |
|---|---|
| ورود کاربران | حساب جدا برای هر نفر، نقش و دسترسی قابل تنظیم، محدودسازی به انبار، قفل خودکار، ثبت هر ورود/خروج و رمز اشتباه با زمان و دستگاه |
| انبارهای تفکیکی | مواد اولیه، مصرفی، یدکی، محصول، ابزار، قرنطینه QC، ضایعات (قابل افزودن/تغییر) |
| کالا و واحد تبدیل | واحد پایه + واحدهای فرعی (بسته، شاخه، کارتن…)، وزن هر واحد برای تبدیل کیلوگرم/تن ↔ عدد، محاسبه وزن لوله و شفت |
| اسناد | رسید انبار، حواله خروج، انتقال بین انبارها، ارسال و برگشت امانی، برگشت/مرجوعی، اصلاحیه، موجودی اول دوره — همه قابل اصلاح (با ثبت علت) و ابطال |
| مجوز | در صورت فعال‌سازی، خروج/امانی/انتقال/اصلاحیه پس از «صدور مجوز» قطعی می‌شود؛ چاپ «مجوز خروج کالا» برای نگهبانی |
| کنترل کیفی | اقلام رسیده تا تایید QC وارد موجودی نمی‌شوند؛ تایید/مشروط/رد با شماره گواهی و نام بازرس |
| انبارگردانی | برگه شمارش (کور)، فرم خام چاپی، ورود شمارش، صدور خودکار سند اصلاحیه |
| گزارش‌ها | مصرف روزانه/هفتگی/ماهانه آیتم به آیتم، گردش کالا، سقف مصرف، پروژه، تحویل‌گیرنده، تامین‌کننده، کاردکس، راکد، پیشنهاد خرید، آمار QC — همه با خروجی اکسل و چاپ |
| سفارشی‌سازی فرم | تغییر برچسب، مخفی/اجباری کردن فیلدها، افزودن فیلد دلخواه، عنوان و امضاهای چاپی |
| گزارش تغییرات | هر ایجاد/اصلاح/ابطال با کاربر، زمان و مقدار قبل ← بعد |
| آموزش | راهنمای هر بخش، شروع سریع، دفترچه چاپی، داده تمرینی |
| ورود از اکسل | همان فایل‌های فعلی (شیت «ورودی» و «خروجی»)؛ تشخیص واحد از متن مقدار («۳۷شاخه»)، حذف ردیف‌های تکراری در ورود دوباره |

## ساختار
```
index.html  style.css  manifest.json  sw.js     ← پوسته و نصب/آفلاین
js/core.js      تاریخ شمسی، ذخیره IndexedDB، گزارش تغییرات
js/domain.js    انواع سند، تبدیل واحد، موجودی، امانی، سقف مصرف
js/auth.js      کاربران و دسترسی‌ها
js/ui.js        منو، جدول، چاپ، اکسل، داشبورد
js/docs.js      فرم سند، مجوز، کنترل کیفی
js/master.js    کالا، انبار، طرف‌حساب، موجودی، امانی، انبارگردانی
js/reports.js   گزارش‌ها و سقف مصرف
js/admin.js     فرم‌ها، کاربران، گزارش تغییرات، تنظیمات
js/sync.js      پشتیبان و همگام‌سازی ابری
js/importer.js  ورود از اکسل
js/help.js      آموزش‌ها
cloud/Code.gs   سرور رایگان Google Apps Script (ابر + صفحه گزارش آنلاین + ایمیل روزانه)
```

## راه‌اندازی ابر
راهنمای کامل داخل برنامه: «آموزش و راهنما ← راه‌اندازی ابر». خلاصه: کد `cloud/Code.gs` را در Apps Script یک Google Sheet بچسبانید، `KEY` را عوض کنید، به‌صورت Web app منتشر کنید و آدرس و KEY را در «تنظیمات ← ابر» وارد کنید.
روش دوم بدون سرور: «پوشه همگام» — یک پوشه Google Drive/OneDrive روی لپ‌تاپ انتخاب شود.

نکته امنیتی: هر کس آدرس وب‌اپ و KEY را داشته باشد به داده‌ها دسترسی دارد؛ KEY را طولانی و محرمانه نگه دارید.
